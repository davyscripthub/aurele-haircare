# AURÈLE — Luxury Haircare

A responsive React + Vite storefront concept with a dark luxury visual direction.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Included
- Luxury landing page and product collection
- Four haircare products
- Functional client-side cart (add, quantity, remove, subtotal)
- About Us footer and responsive mobile navigation

## Before launch
Product photography currently uses remote Unsplash images and prices are sample USD values. Replace these with your own product images, confirmed pricing, brand details and checkout/payment integration. The checkout button is a demo placeholder.
